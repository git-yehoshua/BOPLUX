# Task Format

## Purpose

Define a reusable workspace artifact format.

## How to Use

Use this file when assembling agent-ready project instructions.

## Rules

- Keep guidance grounded in Wiki Layer truth and Governance Layer checks.
- Include change category, task routing, execution mode, evidence level, canonical artifacts, validation expectations, public surfaces, public discovery, runtime/monitoring review, approval gates, and maintenance expectations.
- Ticket-only tasks must be execution-ready, not meta commentary.

## Output Format

Change category, user request, execution mode, evidence level, scope, canonical artifacts, implementation workflow, validation, public surfaces, public discovery, runtime/monitoring review, approval gates, maintenance contract, and reporting expectations.
