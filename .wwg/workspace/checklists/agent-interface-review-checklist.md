# Agent Interface Review Checklist

## Purpose

Review AI-agent-facing UI against governed accountability, evidence, approval, and receipt principles.

Canonical principle source: `.wwg/wiki/principles/ai-agent-interface-principles.md`.
Guidance source: `.wwg/wiki/design-system/agent-interface-guidelines.md`.

## Checklist

- [ ] Does the UI show what the agent is doing?
- [ ] Does it show what is waiting for approval?
- [ ] Does it separate accepted truth from runtime evidence?
- [ ] Are risky actions approval-first?
- [ ] Are receipts generated or linked for meaningful actions?
- [ ] Can users inspect sources and evidence?
- [ ] Can users stop, cancel, or roll back where appropriate?
- [ ] Are uncertainty and failed states clearly communicated?
- [ ] Are model/tool decisions explainable where they affect cost, risk, permissions, or quality?
- [ ] Does the interface avoid implying WWG executes agents or routes runtime tools/models?

## Closeout

Unresolved evidence, approval, or accountability gaps should be recorded before release.
