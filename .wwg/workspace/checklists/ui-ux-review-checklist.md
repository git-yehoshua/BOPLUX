# UI/UX Review Checklist

## Purpose

Review UI changes against the governed UI/UX Simplicity Principle Brief before release.

Canonical principle source: `.wwg/wiki/principles/ui-ux-simplicity-principles.md`.
Guidance source: `.wwg/wiki/design-system/ui-ux-guiding-principles.md`.

## Checklist

- [ ] Is the next useful action obvious?
- [ ] Are primary, secondary, and destructive actions visually distinct?
- [ ] Are too many equal-priority options shown at once?
- [ ] Are advanced options hidden until needed without removing access to them?
- [ ] Are defaults explainable and reversible?
- [ ] Are empty states useful?
- [ ] Are errors actionable?
- [ ] Are loading and status states clear?
- [ ] Is the UI usable by beginners without removing power-user paths?
- [ ] Does the design reduce visible complexity without reducing user control?

## Closeout

Record unresolved issues as release risks, accepted decisions, or follow-up recommendations.
