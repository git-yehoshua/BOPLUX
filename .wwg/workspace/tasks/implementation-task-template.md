# Implementation Task Template

## Purpose

Provide a reusable task handoff format.

## How to Use

Use this template to define bounded agent work.

## Rules

Include goal, scope, inputs, constraints, acceptance criteria, validation, test plan, and report path.

## Test Plan Required

For meaningful implementation tasks, include:

- Behavior changed:
- Unit tests added/updated:
- Regression tests added/updated:
- Manual verification:
- Test command run:
- Result:
- If no tests were added, reason:

Use Governance Test Enforcement to classify the obligation as No Test Required, Test Recommended, Test Required, or Regression Test Required.

## Output Format

A task ticket ready to hand to a coding or research agent.
