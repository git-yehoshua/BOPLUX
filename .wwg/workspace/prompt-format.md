# Prompt Format

## Purpose

Define a reusable workspace artifact format.

## How to Use

Use this file when assembling agent-ready project instructions.

## Rules

- Keep guidance grounded in Wiki Layer truth and Governance Layer checks.
- Prompts should make execution mode explicit.
- Prompts should identify public-surface review and regression guardrail needs when relevant.
- Prompts should identify runtime, public discovery, monitoring, evidence level, and approval-gated needs when relevant.
- Prompts should preserve human-written content outside generated markers.

## Output Format

Role, context, natural prompt, change category, execution mode, evidence level, canonical artifacts, workflow, validation, runtime/discovery/monitoring review, maintenance expectations, and report format.
