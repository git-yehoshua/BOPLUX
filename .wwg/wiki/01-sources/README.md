# Sources

## Purpose

Store evidence and processed source material.

## Contents

- `raw` keeps immutable evidence
- `processed` keeps cleaned extracts and summaries
- Compiled truth should cite or reference relevant sources
- Accessible files, screenshots, docs, and images from external agent chats should be registered through source intake and copied under `raw/uploads`
- Chat-only references that are not accessible as files should be recorded as raw source notes with the limitation documented

## Maintenance

Keep this page current when files are added, renamed, or promoted into compiled project truth.
