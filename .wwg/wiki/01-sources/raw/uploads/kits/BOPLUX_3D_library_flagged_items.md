# Flagged items not downloaded

No individual restricted asset was downloaded. Sketchfab, OpenGameArt.org, and itch.io were not bulk-downloaded because each listing requires per-item license verification and a reliable direct-file URL; no specific asset was treated as safe without that verification. Review candidate listings manually before use.

- [Sketchfab downloadable search](https://sketchfab.com/search?features=downloadable&type=models): per-model license and IP checks required; homepage URL alone does not establish CC0/CC Attribution.
- [OpenGameArt CC0 furniture collection](https://opengameart.org/content/cc0-furniture): collection page does not provide a single verified bulk archive in the fetched content; each linked item needs its own license/file check.
- [itch.io free asset listings](https://itch.io/game-assets/free): itch.io has no site-wide license guarantee; each pack must be checked individually.
