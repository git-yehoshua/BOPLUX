## Storage

The final categorized library occupies approximately **18.6 MB (18,567,576 bytes)**, excluding temporary download archives and staging files. The delivery archive is provided separately as `BOPLUX_assets.tar.gz`.

## Flagged items not downloaded

- [Sketchfab downloadable search](https://sketchfab.com/search?features=downloadable&type=models): individual model pages require per-item verification of Downloadable status, exact license, attribution, and trademark/IP content. The provided homepage URL does not establish those facts, so no Sketchfab model was downloaded without verification.
- [OpenGameArt CC0 furniture collection](https://opengameart.org/content/cc0-furniture): the collection page did not expose one verified bulk archive in the fetched content; each linked item needs its own license and file check.
- [itch.io free game assets](https://itch.io/game-assets/free): itch.io has no site-wide license guarantee; each pack must be checked individually.

No item with CC-BY-NC, CC-BY-SA, editorial, Standard/all-rights-reserved, non-commercial-only, unclear licensing, real trademarks, or licensed IP was downloaded.
