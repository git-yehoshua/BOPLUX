# Game Profile

## Purpose

Define WWG additions for Profile for games, simulations, and interactive play systems.

## Contents

- Apply after the universal base
- Use required questions during discovery
- Add profile gates to governance before release

## Maintenance

Keep this page current when files are added, renamed, or promoted into compiled project truth.

## Profile Product Invariants

- Match outcomes must remain authoritative and replayable.
- Anti-cheat boundaries must not be weakened.
- Bot/AI behavior must be deterministic where required.

## Profile Runtime Truth Concerns

- Match state authority must be explicit.
- Replay/watch systems must derive from authoritative match history.
- Client-side predictions or effects must not replace authoritative outcomes.

## Profile Maintenance Triggers

- Mechanics, balance, match state, bots, replay/watch behavior, ranking, economy, anti-cheat, or telemetry changes.

## Routing Keywords

match, replay, watch, leaderboard, rank, bot, economy, mechanic, skill, balance, progression, anti-cheat, telemetry

## Likely Impact Zones

Game loop, match state, replay/watch systems, ranking, bot behavior, economy, balance, anti-cheat, telemetry, patch notes, event announcements.

## Required Governance Gates

- Core loop tested.
- Authoritative match state reviewed.
- Replay/watch behavior validated.
- Anti-cheat boundaries reviewed.
- Public-surface review completed for patch notes, gameplay updates, balance notes, or event announcements.

## Runtime / Infrastructure Concerns

Match lifecycle, queue/worker execution, replay/watch consistency, leaderboard updates, and anti-cheat signals.

## Public Discovery Concerns

Homepage, patch notes, gameplay updates, leaderboard public pages, and lore/docs hubs.

## Monitoring / Operations Concerns

Match latency, replay readiness, queue stalls, player peaks, and public content correctness.

## Evidence and Approval Notes

Public balance notes, economy changes, and ranked rule changes may be approval-gated. Gameplay/runtime claims should be backed by replay evidence, deterministic tests, telemetry, logs, or authoritative match records.

## Profile Canonical Families

- mechanics
- match lifecycle
- economy
- ranking
- replay/watch
- anti-cheat
- public updates

## Profile Context Governance

Keep mechanics, balance, economy, ranking, replay/watch, and anti-cheat detail in dedicated canonical context or profile files. Master context should summarize only global game invariants and routing.

## Profile Truth Conflict Notes

If live match behavior, replay history, ranking, or balance differs from docs, preserve evidence and resolve through the relevant canonical family.

## Profile Approval-Gated Areas

Ranked rules, economy changes, public balance notes, anti-cheat changes, and player-facing patch approvals.
