# Screens

## Purpose

Track screens and their purpose.

## Compiled Truth

Screen notes should list users, primary actions, states, empty states, errors, and data shown.

## Design Source of Truth

For each meaningful screen, capture:

- Primary user and goal
- Main actions
- Data shown
- Loading state
- Empty state
- Error state
- Responsive behavior
- Admin or public presentation differences

Meaningful UI changes should update this page or the project's canonical design file.
